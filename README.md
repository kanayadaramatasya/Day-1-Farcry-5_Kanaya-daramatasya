## Dokumentasi Kegiatan Workshop
### 1. Rangkuman Materi
#### A. Prompt Engineering
Prompt engineering adalah cara membuat instruksi atau perintah yang jelas agar AI dapat memberikan hasil sesuai dengan kebutuhan kita. Dalam membuat prompt, ada beberapa bagian yang perlu diperhatikan, yaitu:
  - Role: Menentukan peran AI.
  - Task: Menjelaskan tugas yang harus dilakukan.
  - Context: Memberikan informasi atau latar belakang.
  - Format: Menentukan bentuk hasil yang diinginkan.
Dari materi ini, saya belajar bahwa memberikan instruksi dan konteks yang jelas dapat membantu AI menghasilkan jawaban yang lebih sesuai.

#### B. Pengenalan Git dan GitHub
Pada materi ini dijelaskan tentang perbedaan Git dan GitHub.
  - Git: Sistem yang digunakan untuk mencatat dan melacak perubahan pada file atau proyek.
  - GitHub: Platform online untuk menyimpan repository Git dan memudahkan kerja sama dalam mengembangkan proyek.
Ada juga beberapa istilah yang perlu diketahui, seperti:
  - Repository: Tempat untuk menyimpan file proyek.
  - Commit: Proses menyimpan perubahan pada proyek.
  - Branch: Cabang yang digunakan untuk mengembangkan proyek.
  - Pull Request: Cara mengajukan perubahan agar bisa diperiksa dan digabungkan ke proyek.

#### C. Git Workflow
Dalam Git terdapat tiga bagian utama, yaitu:
  - Working Directory: Tempat untuk membuat atau mengubah file proyek.
  - Staging Area: Tempat untuk menyiapkan perubahan sebelum disimpan.
  - Git Directory: Tempat Git menyimpan informasi dan riwayat perubahan proyek.

#### D. Perintah Dasar Git
Ada beberapa perintah Git yang diperkenalkan dalam materi, di antaranya:
  - git init untuk membuat repository Git baru.
  - git add . untuk menambahkan perubahan file ke staging area.
  - git commit -m "message" untuk menyimpan perubahan dengan pesan.
  - git push origin main untuk mengirim perubahan ke GitHub.
  - git pull origin main untuk mengambil perubahan dari repository online.

#### E. Praktik Membuat Proyek dengan AI dan GitHub
Pada kegiatan ini, peserta diperkenalkan dengan praktik membuat aplikasi sederhana bernama Student Task Planner menggunakan bantuan AI antigravity. Setelah aplikasi dibuat, proyek dimasukkan ke Git, kemudian disimpan ke GitHub menggunakan proses commit dan push. Peserta juga belajar melakukan perubahan pada proyek dan mengunggah kembali perubahan tersebut ke GitHub
